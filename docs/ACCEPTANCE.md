# 실제 기기 인수 검사

자동 검사와 별개로 수행할 사용자 흐름 체크리스트다. 아래 V01–V29는 완료 표시가 아니며 실기기 검사 후 결과를 기록한다. 현재 자동 검사 결과는 [검증 현황](VERIFICATION.md)을 따른다.

## 테스트 시작 조건

- 쓰기·삭제·공격성 권한 검사는 사용자가 허용한 **격리 Supabase**에서만 실행한다. 실제 테스트 계정 A=작성자, B=언어 자격 교정자/편지 상대, C=무관한 사용자, anon=비로그인을 분리한다.
- 대상 환경의 migration·함수 정의·grants·RLS·버킷 설정을 확인한다. OAuth redirect와 인증 사용자의 파일/기능 왕복을 추가 확인한다. 소스 존재는 적용 증거가 아니다.
- 본문은 합성 예문, 사진/필기는 직접 만든 테스트 fixture만 사용한다. 운영 일기·쪽지·자격증명은 로그로 복사하지 않는다.
- 비용표·공개정책·관계모델·삭제정책과 기준 기기/OS·회선·성능 목표를 검사 전에 고정한다. 미정 정책 때문에 기대값을 바꿔 PASS를 만들지 않는다.
- 검증할 버전을 실제 기기에 설치한다. 구매·구독 화면/버튼은 유지하고 이용 불가 안내 후 복귀하며 스토어·실결제 호출이 없는지 확인한다. 향후 도입은 별도 검증이다.
