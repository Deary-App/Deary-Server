## 토큰과 날짜 주의점

하루 토큰은 국적 대표 시간대, 새 일기 작성일은 한국시간이다. 서로 다른 현행 기준을 임의로 하나로 설명하지 않는다. 프로필 국적 수정은 이미 설정한 토큰 시간대를 즉시 바꾸지 않는다. 잔액은 클라이언트에서 계산해 저장하지 않는다. 과거 가입 보너스 원장과 기존 잔액은 보존한다.

## 화면과 개발 범위

디자인이 없는 화면은 기능 확인에 필요한 최소 구성으로 만들고 표현과 데이터·동작을 분리한다. 확정 화면과 사용자 수정 사항을 우선한다. 댓글·이웃·편지·필기·복습을 전체 목표에서 임의로 제외하지 않는다. [로드맵](ROADMAP.md)의 구현 여부와 [인수 검사](ACCEPTANCE.md)의 기기 검증은 별개다. [분석 설계](ANALYTICS.md)는 구현·활성화 지시가 아니다.
